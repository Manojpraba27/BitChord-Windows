# Run separately on Windows 10 and Windows 11

- Install as a standard user; check name/icon and Start Menu/desktop shortcuts.
- Launch portable without installation; verify no console window.
- Play MP3/WAV/FLAC, pause/resume, seek, next/previous, mute and adjust volume.
- Test corrupt/missing files and embedded artwork.
- Rename/reorder/remove playlist entries; restart and verify settings/playlists/artwork.
- Test hardware media keys, tray background playback, taskbar and notifications.
- Test authenticated streaming and lyrics with real accounts.
- Uninstall; confirm application files removed and personal music/user data retained.

Record OS build, app hash, result and evidence for each item. None of these native acceptance checks has been completed here.
